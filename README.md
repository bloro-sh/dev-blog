# Bloro Blog

A personal blog where I document my journey in software development, what I learn, and the projects I work on.

Built with Astro and TypeScript, using Markdown and MDX for content.

## Tech Stack

- Astro
- TypeScript
- CSS
- Markdown / MDX

## Credits

This blog is built with [Tone](https://github.com/hanityx/astro-tone), a minimal Astro blog starter.
